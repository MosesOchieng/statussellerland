---
name: Social channel branding
description: How StatusSeller represents social platforms in the landing page when external logo assets are unavailable.
---

StatusSeller's channel strip should remain self-contained: use local assets already supplied to the project and lightweight inline brand marks instead of runtime-dependent external logo URLs.

**Why:** The external image-search capability may require a paid mode, while the landing page needs predictable static hosting and should not depend on third-party image availability.

**How to apply:** Keep platform marks small, recognizable, and paired with accessible text labels. Prefer local assets when the user provides them; use inline SVG/CSS marks for simple social-brand symbols.
